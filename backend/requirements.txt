# Meeting Assistant Backend Dependencies
# =======================================
# This file aggregates every dependency group for local/conda development
# (e.g. the `meetAssistant` conda env) so `pip install -r requirements.txt`
# and `pytest backend/tests` keep working unchanged.
#
# Docker images install these groups selectively instead of using this file
# directly — see backend/Dockerfile (targets: light, heavy) — so that the API
# and worker-light images don't carry faster-whisper/pyannote, and no image
# carries the dev/test tools. PyTorch is installed separately in the
# Dockerfile (CPU or CUDA wheel index); install it yourself for local dev.
#
# Groups:
#   requirements-base.txt   web framework, db, celery, docs, google, etc.
#   requirements-ml.txt     transformers/sentence-transformers/tiktoken
#   requirements-heavy.txt  faster-whisper/pyannote.audio/torchcodec/ffmpeg-python
#   requirements-dev.txt    pytest and friends

-r requirements-base.txt
-r requirements-ml.txt
-r requirements-heavy.txt
-r requirements-dev.txt
